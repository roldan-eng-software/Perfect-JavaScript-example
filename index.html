Perfect JavaScript Example

Portfólio técnico sem frameworks, sem bibliotecas, sem build: apenas JavaScript moderno (ES2023+), HTML semântico e CSS enxuto. Cada seção abaixo é uma demonstração real — e mostra o código-fonte que a implementa.

Closure é uma função que mantém acesso ao escopo onde foi criada, mesmo depois de esse escopo sair da pilha — aqui um contador vive dentro de criarContador() sem variável global. Usei closures porque encapsulam estado sem classes; compose/pipe/curry compõem lógica pura; memoize cacheia resultados e a comparação usa performance.now().
async/await torna o código assíncrono sequencial e legível; Promise.all paraleliza, allSettled tolera falhas parciais e race + timeout implementam deadline. Usei AbortController porque cancelar requisição é obrigatório em UI real, e retry com backoff porque rede falha — os estados loading/erro/vazio/sucesso sempre aparecem.
A ordem no JS não é a ordem do texto: código síncrono roda primeiro, depois a fila de microtasks (Promise.then, queueMicrotask) esvazia por completo, e só então vêm macrotasks (setTimeout) e requestAnimationFrame. Demonstro isso executando a sequência e numerando cada passo — útil para entender bugs de concorrência.
Observers reagem a mudanças sem poluição de listeners: IntersectionObserver faz reveal/scroll-spy, ResizeObserver mede layout, MutationObserver observa alterações. Combinei com delegação de eventos, <template> e DocumentFragment para renderizar listas grandes com um único reflow — em vez de N.
Uma mini store com pub/sub mantém UI e dados dessincronizados. Usei imutabilidade (spread + structuredClone) para mudanças rastreáveis, selectors para leituras pontuais, Proxy para reatividade reativa e localStorage para persistir — com try/catch, porque storage pode estar bloqueado.
Campos privados # dão encapsulamento real (não é convenção, é sintaxe); getters/setters validam; static blocks configuram a classe no carregamento; herança e mixins cobrem reuso, e WeakMap/Symbol são alternativas "à moda antiga" comparadas lado a lado com fábrica de funções.
function* produz valores sob demanda — perfeitos para sequências infinitas e paginação; Symbol.iterator torna qualquer objeto iterável por for…of; async generators + for await...of consomem APIs paginadas com elegância. Incluí Map/Set/WeakSet e detecção de iterator helpers com fallback.
Código pesado na main thread congela rolagem, cliques e animações. Um Worker roda o cálculo em outra thread com postMessage, barra de progresso e cancelamento por worker.terminate(). A demo compara os frames renderizados com e sem o worker — a diferença é visível.
Constraint Validation API (setCustomValidity, checkValidity, reportValidity) dá validação nativa com mensagens próprias; máscaras de CPF/CEP/telefone feitas à mão, validação em tempo real com debounce, mensagens ligadas por aria-describedby/aria-live, e FormData + Object.fromEntries para coleta limpa.
O Kanban usa a HTML5 Drag and Drop API e uma alternativa completa por teclado (setas movem cartões entre colunas) — arrastar com mouse não pode ser a única via. A ordem é persistida em localStorage, e cada movimento é anunciado em aria-live.
A API Intl nativa cobre moeda, data, tempo relativo, listas, plurais e ordenação — zero bibliotecas. Trocar entre pt-BR/en-US/es atualiza o DOM na hora, sem recarregar, usando dicionários JSON e textContent.
Contadores em tempo real mostram a diferença entre debounce e throttle; requestAnimationFrame sincroniza com o frame; virtualização renderiza só a janela visível de 10.000 itens (~20 nós no DOM, não 10.000); performance.mark/measure mede com precisão de milissegundos.
Clipboard, Web Share, Geolocation, matchMedia, Page Visibility, Notification, URLSearchParams, History API, BroadcastChannel (entre abas!) e <dialog> — todas com feature detection ('x' in window) e fallback amigável. Nenhuma permissão é pedida automaticamente: geolocation e notificação são opt-in.

Testes

Os utilitários têm testes unitários com o runner nativo do Node (node:test + node:assert) — sem Jest, sem Vitest. Rode com npm test.

  • tests/debounce.test.js — timers com mock.timers
  • tests/throttle.test.js — leading/trailing/cancel
  • tests/memoize.test.js — cache, resolver, clear
  • tests/compose.test.js — compose/pipe/curry e erros
  • tests/retry.test.js — backoff exponencial, cause, abort
  • tests/store.test.js — subscribe/unsubscribe/imutabilidade
  • tests/validators.test.js — CPF/CEP/e-mail/senha
  • tests/format.test.js — Intl number/date/list/plural/collate
  • tests/highlight.test.js — tokenizador puro do <code-peek>

Como foi feito

Cada módulo tem cabeçalho padronizado (ARQUIVO/PROPÓSITO/CONCEITOS/USADO EM) e JSDoc completo nas exportações. Comece pelos utilitários puros — são a base testável de tudo.

  • core/dom.js — helpers $, h(), delegação
  • core/store.js — mini store pub/sub imutável
  • core/event-bus.js — EventTarget como barramento
  • core/router.js — roteador por hash + History API
  • core/storage.js — localStorage seguro com fallback
  • core/logger.js — logger com níveis por flag
  • utils/debounce.js — atraso por inatividade
  • utils/throttle.js — limite por intervalo
  • utils/memoize.js — cache por argumentos
  • utils/compose.js — compose/pipe/curry
  • utils/retry.js — retry com backoff exponencial
  • utils/sleep.js — pausa cancelável
  • utils/deep-clone.js — clone profundo com fallback
  • utils/format.js — formatação Intl
  • utils/validators.js — validações puras
  • utils/highlight.js — tokenizador de sintaxe
  • components/code-peek.js — exibe o código real
  • components/demo-card.js — cartão de seção
  • components/toast-notification.js — avisos
  • components/theme-toggle.js — tema claro/escuro
  • components/accessible-tabs.js — abas ARIA
  • docs/ARCHITECTURE.md — diagrama e ciclo de vida
  • docs/JS-TECHNIQUES.md — tabela de técnicas
